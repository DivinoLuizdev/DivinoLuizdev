# 👋 Olá, eu sou o Divino Luiz!

Sou **Analista de Automação** com experiência em **RPA, desenvolvimento de software, integrações e automação de processos**.

Atualmente atuo na criação e sustentação de soluções de automação, utilizando **Python, UiPath, Power Automate e APIs**, além de conhecimentos em **Java, Spring Boot, Angular e bancos de dados**.

Tenho experiência em desenvolvimento de automações de ponta a ponta, desde a análise do processo e definição da solução até o desenvolvimento, testes, implantação e suporte em produção.

Meu objetivo é unir **automação, desenvolvimento de software e Inteligência Artificial** para criar soluções mais eficientes, escaláveis e integradas.
